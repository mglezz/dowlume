# Dowlume 0.6.0 — Organización periódica y actualizaciones

[English](../../releases/0.6.0.md) · [Registro de aceptación](acceptance/0.6.0.md)

La versión 0.6.0 está disponible para Windows x64, macOS 15+ Apple Silicon y Ubuntu 24.04 LTS x64 con GNOME. Se mantiene el [alcance de plataformas y sistemas de archivos](../user/platform-support.md).

## Cambios

- Nuevo icono geométrico con una D y una flecha de descarga verde menta integrada; PNG de alta resolución y formatos adaptados a Windows, macOS y Linux.
- Organización periódica opcional: intervalo de 1 a 1440 minutos, con 10 por defecto. Exige vista previa y confirmación. La primera pasada espera; cada pasada posterior espera un intervalo completo tras terminar la anterior. Pausar espera el trabajo activo y cada inicio queda pausado.
- Búsqueda manual de actualizaciones en Ajustes. Las instalaciones registradas de Windows pueden descargar el instalador oficial, verificar tamaño y SHA-256 y abrirlo después del cierre ordenado. Se instala sobre la copia existente sin desinstalar. Las demás distribuciones abren las instrucciones oficiales. No hay consultas periódicas de red ni instalación automática.
- Búsqueda en Revisión sin alterar los totales y selección de pestañas más clara.
- Interfaz, confirmaciones y documentación en inglés y español; ajustes compatibles con perfiles anteriores.

Se conservan las comprobaciones para descargas ocupadas, recientes, excluidas e incompletas, los movimientos sin sobrescritura, el historial, la recuperación y Deshacer cuando procede. No se importan subcarpetas existentes. La papelera nativa sigue desactivada.

## Instalación y privacidad

Cierra Dowlume y copia el perfil completo antes de actualizar. Instala el paquete Windows sobre la instalación existente o utiliza `sudo apt install ./dowlume_0.6.0_amd64.deb` en Ubuntu. Extrae los portables completos en otra carpeta permanente. Se conservan perfiles y archivos organizados. La versión 0.5.0 no incluye el botón: el primer salto a 0.6.0 usa el instalador o archivo habitual.

Las consultas a GitHub son manuales y no envían cuenta, credenciales, nombres de archivos ni rutas. GitHub recibe los datos habituales de conexión, como la dirección IP. Las sumas verifican la coherencia con los metadatos publicados, no una firma independiente. Windows/Linux siguen sin firmar; macOS utiliza firma ad hoc sin Developer ID ni notarización. Se incluye .NET.

Consulta la [guía](../user/guide.md) y el [registro de aceptación](acceptance/0.6.0.md) para las comprobaciones exactas, huellas y límites pendientes. Este documento incluido al compilar no certifica por sí mismo publicación ni aceptación manual. Los paquetes aceptados deben conservarse sin recompilar al publicarlos.
