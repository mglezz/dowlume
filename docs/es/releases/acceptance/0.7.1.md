# Dowlume 0.7.1 — Aceptación final

Publicación autorizada por el mantenedor el 14 de noviembre de 2026. Se conservan los paquetes de 0.7.0 sin modificarlos. Los mismos bytes comprobados se promocionan sin recompilar.

Revisión definitiva: `306aa2dee51c867708b109cb9f74df941d6e17b9`, conservada en el PR #55. Los tres manifiestos indican 0.7.1 y árbol limpio. La revisión de CI tiene el mismo contenido que `beec09c99a5ddda87c021918914eec58155b89c4`. Se inspeccionaron las guías rápidas incluidas en los tres archivos portables: versión y navegación 0.7.1. El candidato anterior con guías antiguas queda descartado.

Pasaron las diez comprobaciones. Evidencia: [Windows](https://github.com/mglezz/dowlume/actions/runs/43630987009), [macOS/Linux](https://github.com/mglezz/dowlume/actions/runs/43630987001), [tests](https://github.com/mglezz/dowlume/actions/runs/43630987013), [security](https://github.com/mglezz/dowlume/actions/runs/43630987025).

Windows comprueba actualización desde la 0.7.0 fijada por hash, actualizador de producción, portable, idiomas y menús nativos de tema, bandeja e inicio oculto/visible, bloqueos durante la ejecución, desinstalación y conservación del perfil/archivos. macOS 15 arm64/APFS y Ubuntu x64/ext4 comprueban el flujo nativo, reglas, agrupación de carpetas y parada de monitores. La suite local funcional pasó 156 pruebas, con 48 omisiones por plataforma.

No se infiere aceptación manual adicional ni certificación de una máquina sin runtimes compartidos, una nueva instalación manual Ubuntu o una sesión real GNOME/Wayland. Windows sigue sin firma de editor y macOS usa firma ad hoc. Se mantienen las limitaciones de plataforma. La descarga pública posterior se verifica contra estas huellas; el resultado se registra en el PR #55.
