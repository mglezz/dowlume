# Dowlume 0.7.2 — Volver a abrir la aplicación activa

[English](../../releases/0.7.2.md)

Actualización de mantenimiento todavía no publicada. Las descargas de 0.7.1 se conservan sin cambios.

Abrir Dowlume de nuevo muestra la instancia que ya usa ese perfil. Restaura su ventana si está minimizada u oculta en la bandeja y conserva la maximización. Los diálogos de confirmación siguen accesibles. El segundo proceso termina sin abrir la base de datos ni iniciar otro monitor.

Se mantiene el bloqueo exclusivo del perfil. La activación usa un canal local del mismo usuario, separado por perfil y con tiempo de espera limitado; solo acepta mostrar la ventana, nunca rutas ni órdenes arbitrarias. Windows concede el permiso de primer plano cuando lo permite el sistema. Si la instancia no responde o pertenece a una versión anterior sin este canal, se conserva el aviso de arranque para evitar abrir el perfil simultáneamente.

Las pruebas cubren peticiones repetidas y simultáneas, perfiles independientes, cierre/reinicio del canal y restauración de ventanas. La aceptación del paquete Windows abre un segundo proceso con la primera ventana visible, minimizada y oculta, y verifica que se restaura el proceso original y el segundo termina correctamente.
