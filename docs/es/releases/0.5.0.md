# Dowlume 0.5.0 — Linux (sin publicar)

[English](../../releases/0.5.0.md) · [Plan de aceptación](../../development/linux-acceptance.md)

Implementación de la próxima versión. La ejecución nativa Linux y la aceptación final
de escritorio y paquetes siguen pendientes; no es una publicación estable.

- Adaptador Linux x64 con descriptores, identidad `statx`, SHA-256, movimientos atómicos
  `renameat2` sin sobrescritura, persistencia de directorios y recuperación SQLite.
- Organización y supervisión compartidas, Conservar, Posponer, Mover y Deshacer elegible.
- Descargas XDG, inicio de sesión opcional, menú/icono, apertura de carpeta, idiomas
  español/inglés y cierre ordenado sin bandeja.
- Preparación de `.deb` Ubuntu y `.tar.gz` portable glibc x64 autocontenidos, dependencias,
  sumas de comprobación y procedencia. Sin publicación automática.

Objetivo inicial: **Ubuntu 24.04 LTS x64, GNOME y ext4 local del mismo montaje**, con
UUID y fecha de creación verificables. Se rechazan almacenamiento no verificable,
enlaces y movimientos entre montajes. Los bloqueos POSIX son cooperativos; las carreras
detectadas conservan archivos para revisión. Consulta el [contrato Linux](../../architecture/linux.md).

Fedora y Arch pueden usar el mismo portable candidato sobre ext4 compatible; siguen sin
validación oficial. Btrfs/XFS no están habilitados. Se mantienen los adaptadores Windows
y macOS. Linux inicia un perfil estable nuevo y conserva la vista previa anterior sin
migrarla automáticamente. No se presupone una versión Linux estable anterior.

Antes de publicar: pruebas nativas, ext4/udev real, interrupción/reinicio/espacio/permisos,
instalación/actualización/desinstalación, inicio real y ambos idiomas en GNOME X11/Wayland,
indicando si usa XWayland. En esta sesión de desarrollo macOS no se han generado paquetes
Linux ni hashes de aceptación.
