# Dowlume 0.5.0 — Ubuntu Linux, Windows y macOS

[English](../../releases/0.5.0.md) · [Registro de aceptación](acceptance/0.5.0.md)

[Dowlume 0.5.0](https://github.com/mglezz/dowlume/releases/tag/v0.5.0) incorpora el flujo
nativo Linux en **Ubuntu 24.04 LTS x64, GNOME y ext4 local del mismo montaje**.
Mantiene Windows x64 y macOS 15+ Apple Silicon dentro del
[alcance publicado](../user/platform-support.md).

- Organización de descargas completas, supervisión, revisión, Conservar, Posponer,
  Mover y Deshacer elegible.
- Movimientos Linux con descriptores, identidad persistente, SHA-256, renombrado
  atómico sin sobrescritura, persistencia de directorios y recuperación.
- Descargas XDG, inicio opcional, menú/icono, gestor de archivos, interfaz bilingüe
  y cierre ordenado sin bandeja.
- Instalador Ubuntu (`.deb`) y portable Linux (`.tar.gz`) autocontenidos.
- El registro del menú conserva entradas modificadas e impide que una copia antigua
  elimine la entrada de una copia nueva tras actualizar.
- La aceptación Windows comprueba la actualización desde 0.4.0 fijada por hash.

## Instalación y límites

Cierra Dowlume antes de actualizar y respalda el perfil. En Ubuntu utiliza
`sudo apt install ./dowlume_0.5.0_amd64.deb`. Extrae los portables completos en una
carpeta permanente separada; no sobrescribas una copia en ejecución. .NET va incluido.
Consulta la [guía de uso](../user/guide.md) para dependencias nativas e inicio de sesión.

Linux requiere UUID y fecha de creación verificables. Rechaza movimientos entre
montajes, enlaces, Btrfs/XFS y sistemas de red/FUSE/overlay. Fedora y Arch siguen sin
validación oficial. La confirmación de sesiones GNOME no certifica un backend Wayland
nativo; no se registró el backend gráfico por separado. macOS requiere APFS local del
mismo volumen. Utiliza carpetas fuera de sincronización. La papelera sigue desactivada.

Windows/Linux no tienen firma de editor; macOS utiliza firma ad hoc sin Developer ID
ni notarización. El perfil Linux de vista previa permanece sin migración automática.

## Aceptación

El 2026-11-01 el mantenedor confirmó las pruebas manuales correctas de `0.5.0-rc.1`.
La corrección final del menú tiene regresiones de conservación que fallan con el
código anterior, CI nativa en los tres sistemas y pruebas de los paquetes finales.
No se afirma una segunda prueba manual de los paquetes nuevos ni mediciones adicionales
en máquinas limpias. Los informes originales conservan sus campos de automatización.
El [registro](acceptance/0.5.0.md) conserva revisiones, enlaces CI, hashes originales
de la candidata y límites de evidencia.
