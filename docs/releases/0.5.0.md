# Dowlume 0.5.0 — Ubuntu Linux, Windows and macOS

[Español](../es/releases/0.5.0.md) · [Acceptance record](acceptance/0.5.0.md)

[Dowlume 0.5.0](https://github.com/mglezz/dowlume/releases/tag/v0.5.0) adds the native
Linux workflow on **Ubuntu 24.04 LTS x64, GNOME and local ext4 on the same mount**.
Windows x64 and macOS 15+ Apple Silicon remain supported within the
[platform scope](../user/platform-support.md).

- Organize completed downloads, monitor new files, review older files, Keep, Snooze,
  Move and undo eligible actions.
- Linux native moves use file descriptors, persistent identity, SHA-256 verification,
  atomic no-overwrite renames, directory persistence and interruption recovery.
- XDG Downloads, optional login startup, menu/icon registration, file-manager reveal,
  English/Spanish UI, and graceful close without a tray.
- Self-contained Ubuntu Installer (`.deb`) and Linux Portable (`.tar.gz`).
- Portable menu registration preserves modified entries and refuses removal by an
  older copy after upgrading to a newer location.
- Windows package acceptance now checks upgrading from the hash-pinned 0.4.0 installer.

## Installation and limits

Close Dowlume before updating and back up your profile. On Ubuntu, use
`sudo apt install ./dowlume_0.5.0_amd64.deb`. Extract portable applications completely
into a separate permanent folder; do not overwrite a running copy. The .NET runtime
is included. See the [user guide](../user/guide.md) for native dependencies and startup.

Linux requires a verifiable filesystem UUID and creation time. Cross-mount moves,
links, Btrfs/XFS and network/FUSE/overlay filesystems are refused. Fedora and Arch
remain unverified. GNOME session confirmation does not certify a native Wayland
rendering backend; the actual backend was not separately recorded. macOS requires
local APFS on the same volume. Use local folders outside synchronization services.
Native recycling remains disabled everywhere.

Windows/Linux packages are unsigned. macOS is ad-hoc signed without Developer ID or
notarization. The old Linux preview profile is preserved without automatic migration.
