# Dowlume 0.5.0-rc.1 — Linux candidate

[Español](../es/releases/0.5.0.md) · [Acceptance plan](../development/linux-acceptance.md)

[Version 0.5.0-rc.1](https://github.com/mglezz/dowlume/releases/tag/v0.5.0-rc.1) is the
Linux test candidate prepared on 2026-10-28. Native CI and extracted-package checks
passed on the exact source below; final manual acceptance remains pending. Version
0.4.0 remains the latest stable release. See the [acceptance record](acceptance/0.5.0.md).

- Native Linux x64 adapter: descriptor-based reads, `statx` identity, SHA-256 verification,
  atomic no-overwrite `renameat2`, directory persistence and SQLite interruption recovery.
- Full shared organization workflow, monitoring, Keep, Snooze, Move and eligible Undo.
- XDG Downloads and optional login startup, application-menu entry/icon, folder reveal,
  English/Spanish interface, and graceful window-close without a tray.
- Self-contained Ubuntu `.deb` and portable glibc x64 `.tar.gz` build scripts, explicit
  native dependencies, checksums and build provenance. No automatic publication.

Initial target: **Ubuntu 24.04 LTS x64, GNOME, local ext4 within the same mount**,
with filesystem UUID and creation time verification. Unsupported/unverifiable storage,
cross-mount moves and links are refused. POSIX locks are cooperative; detected races
retain files for review. See the [native contract](../architecture/linux.md).

Fedora and Arch can use the same portable candidate on compatible local ext4; neither
is officially validated. Btrfs/XFS are not enabled. Windows and macOS retain their
existing adapters. Linux starts a new stable profile and preserves the older preview
profile without automatic migration. No stable Linux upgrade history is claimed.

Before stable release: real-machine ext4/udev verification, forced crash/reboot/space
cases, clean Linux install/update/remove, actual login, and both languages in real
GNOME X11 and Wayland sessions (recording whether rendering uses XWayland). Automated
ext4 fixtures, permissions/races and the package lifecycle passed in CI. No manual
Linux acceptance is inferred from those results.
