# Dowlume 0.7.1 — Clearer settings and reliable dropdowns

[Español](../es/releases/0.7.1.md) · [Settings safety review](../development/settings-safety-review.md)

Maintenance release for Windows x64, macOS 15+ Apple Silicon and Ubuntu 24.04 LTS x64 with GNOME. Upgrade an existing Windows installation without uninstalling; your profile and organized files are retained. Published 0.7.0 downloads remain unchanged.

## Changes

- Settings opens on **Folders and rules**, followed by **Automation**, **Appearance** and **Application**. Folder editors expand individually; the save action stays visible while scrolling.
- Theme and rule dropdown options own their translated labels, so opening a popup no longer depends on finding the main window across a separate visual root. Language changes update existing options. Temporary empty selections during control initialization never overwrite the saved theme or rule mode.
- Theme and language remain available while monitoring. File organization and application options still require paused monitoring. Immediate preferences do not save pending rule edits.
- Whole-folder collection remains disabled by default and appears under advanced automation. Both settings and the start confirmation explain that moving folders changes paths, can break projects or shortcuts, and has no automatic undo.
- English and Spanish guides and packaged Windows UI acceptance navigation follow the new sections.

Existing classification, preview consent, recovery, interval limits and collision protections remain in force. No files are deleted by changing settings or removing a custom rule. Whole-folder stability checks cannot guarantee that another application is not using a directory; use collection only for completed downloads outside working directories.

## Validation

Regression coverage opens the actual theme and rule popups in both interface languages and light/dark appearance, checks visible option labels and persisted selections, renders all four sections at the minimum window size, and checks that reopening Settings returns to folders. The shared suite covers validation conflicts, consent invalidation and safe folder collection. Native platform and packaged acceptance results are available on the pull request; this note does not claim a new manual installation acceptance.

## Installation and privacy

Windows packages are unsigned; macOS uses an ad-hoc signature without notarization. The runtime is included. Update checks contact GitHub only on request; organization remains local. See the [platform scope](../user/platform-support.md). Final package evidence and SHA-256 values are recorded in the online release notes.
