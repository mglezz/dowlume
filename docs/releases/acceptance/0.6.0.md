# Dowlume 0.6.0 acceptance

[Español](../../es/releases/acceptance/0.6.0.md) · [Release notes](../0.6.0.md)

## Preparation — 2026-11-07

The maintainer requested validation and preparation of the definitive 0.6.0 release. This authorizes preparation; it is not a report of manual testing of these new binaries.

The candidate adds native periodic-organization acceptance to extracted packages, using the real one-minute minimum interval and production movers. Windows package acceptance upgrades the hash-pinned published 0.5.0 installation through the production update downloader, size/hash verifier and installer launcher. That integration supplies controlled release metadata and the actual candidate installer bytes; it does not impersonate a published future GitHub release or claim a manual button-to-installer review.

The final source revision, CI runs, package checksums and observed results are recorded below. Builds must report `DirtyWorkingTree: false`. No binary is approved by earlier 0.5.0 evidence.

## Evidence limits

The superseded Windows packaging run [42372742815](https://github.com/mglezz/dowlume/actions/runs/42372742815) stopped before packaging when the durable-queue regression timed out after 35/40 files on shared CI storage, without background file errors. Its timeout was increased from 60 to 120 seconds while retaining all 40 content, journal, exclusion and shutdown assertions. Packages from the pre-icon source are superseded by the final artwork revision and must not be promoted.

Hosted runners do not establish clean-machine independence or real login, suspend/resume, physical power-loss or human desktop acceptance. Linux uses Xvfb and disposable ext4, not a real GNOME Wayland session. macOS requires native APFS checks. Windows/Linux remain unsigned; macOS remains ad-hoc signed. Native recycling stays disabled. Any unperformed checks must remain explicit when deciding publication status.

## Final candidate — 2026-11-07

Source: `b930306a090980e2e8d12eb8a7d2f277aae36094`, preserved in main by [PR #46](https://github.com/mglezz/dowlume/pull/46). All three build manifests report version 0.6.0 and `DirtyWorkingTree: false`. The five downloaded application files were hashed locally and matched their CI manifests; the same bytes are retained for promotion.

- [Windows packages](https://github.com/mglezz/dowlume/actions/runs/42408969037): passed on Windows build 26100 x64. Upgrade from the pinned 0.5.0 installer through the production downloader/verifier/launcher, portable launch, languages and persistence, tray restoration, running-app guards, startup registration retention/removal, uninstall and profile/file retention passed. The native periodic workflow waited a real minute and passed.
- [macOS/Linux packages](https://github.com/mglezz/dowlume/actions/runs/42408973553): passed on macOS 15.8.2 arm64/APFS and Ubuntu x64/ext4. Extracted applications passed native organization, review, Keep/Snooze/Move/Undo, reopened journal, watcher drain and periodic interval/drain. macOS includes the 1024 px icon; the Linux portable icon matches the source artwork.
- [Source checks](https://github.com/mglezz/dowlume/actions/runs/42408953546): passed on all three targets, including disposable APFS case-sensitive and case-insensitive matrices and Linux ext4 checks. [PR checks](https://github.com/mglezz/dowlume/actions/runs/42408958260) passed on attempt 2: attempt 1 passed macOS tests and both 25-test APFS matrices but its formatter was terminated with exit 137 without a formatting diagnostic. Only the failed job was retried; the failure remains in the run history.
- [Security checks](https://github.com/mglezz/dowlume/actions/runs/42408958455): passed. Local Release build had no warnings/errors; 140 tests passed with 48 platform skips, format and repository checks passed, and packaging tests passed 6 with 1 platform skip. Headless compact Spanish review rendering was inspected; it is not human desktop acceptance.
