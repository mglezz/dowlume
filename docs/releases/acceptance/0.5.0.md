## Candidate delivery — 2026-10-28

[0.5.0-rc.1](https://github.com/mglezz/dowlume/releases/tag/v0.5.0-rc.1) is a prerelease
for manual testing, not stable acceptance. All application binaries were built from
clean source [`e19dfe9cd8eebe0aed6268f86dbc5c92293e0e65`](https://github.com/mglezz/dowlume/commit/e19dfe9cd8eebe0aed6268f86dbc5c92293e0e65), merged through
[PR #38](https://github.com/mglezz/dowlume/pull/38). `BUILD-INFO` reports
`DirtyWorkingTree: false` for Windows, macOS and Linux. Later documentation commits
do not change the binaries. The build timestamps use UTC on October 27; candidate
delivery is dated October 28 in Europe/Madrid.

Linux ran on Ubuntu 24.04 x64, kernel `6.17.0-1022-azure`, glibc 2.39, using a newly
created disposable ext4 loop image. The runner supplies a UUID alias for its generated
volume when udev does not. The suite covers native identity/metadata, collision and
race preservation, links/FIFOs, permissions, unsupported storage, full lifecycle,
monitoring and reopened journals before/after rename. The extracted package runs under
Xvfb; this is not a real GNOME X11 or Wayland session. Fedora and Arch remain unverified.
The `.deb` was built and hashed; Linux installer execution is not covered by this smoke test.

The hosted Windows machine has shared .NET runtimes, so its successful package tests
do not establish clean-machine independence. macOS is ad-hoc signed without Developer
ID/notarization; Windows and Linux packages are unsigned. Native recycling remains disabled.

## Remaining before stable publication

- Run both languages through actual GNOME X11 and Wayland desktops; record the rendering
  backend, including XWayland if used. Test dialogs, reveal, scaling, close and restart.
- Test the `.deb` on a clean Ubuntu installation, upgrade/remove/reinstall and running-app
  refusal; test portable relocation, menu registration/removal and profile preservation.
- Verify opt-in startup through a real logout/login, desktop disable overrides and removal.
- Verify normal udev UUID discovery on real local ext4, cross-mount/bind-mount rejection,
  unsupported filesystem and casefold cases, advisory locks and low-space behavior.
- Force process interruption at journal/rename boundaries, reboot and power loss only on
  disposable guests. Reopened-journal fixtures do not replace these failure tests.
- Retain Windows/macOS regressions; obtain explicit final functional acceptance for the
  chosen candidate. No prior 0.4.0 manual confirmation is reused for these binaries.

Use the [Linux acceptance plan](../../development/linux-acceptance.md) to record evidence.
Version 0.4.0 remains latest stable. This prerelease does not approve stable publication.
