# Dowlume 0.7.0 acceptance

[Español](../../es/releases/acceptance/0.7.0.md) · [Release notes](../0.7.0.md)

## Preparation — 2026-11-12

The maintainer explicitly requested a full review and authorized stable publication if verification succeeds, using the 0.6.0 naming and description scheme. This is conditional publication authorization, not a report of new manual testing. Final source, CI runs and exact package hashes will be recorded after candidate validation; existing 0.6.0 or development builds do not approve new bytes.

The release review updates packaged quick starts and current guides, switches Windows upgrade acceptance to the hash-pinned published 0.6.0 installer, avoids repeated preview journal reads, moves settings reads off the UI thread, skips minimized-window polling and fixes recursive database access after theme persistence failure. Regression tests preserve unresolved-file exclusion and theme rollback.

## Performance observation

A disposable local Windows 11 build 26200 x64 test used 100 files of 4 KiB and 2,000 completed history entries. Five Release runs before/after the journal-read change produced median preview times of 2,516.87 ms and 231.36 ms (about 10.9 times faster for this fixture). Individual runs were 2533.98, 2516.87, 2544.17, 1688.23, 1684.23 ms before and 258.64, 231.36, 249.80, 226.14, 216.33 ms after. The fixture used immediate readiness to isolate journal/preview overhead, with the production file hasher and SQLite store. Production readiness delays were not removed. This is not an end-to-end download latency, cross-platform performance baseline or clean-machine benchmark. No personal Downloads were used.

## Evidence limits

Hosted runners do not establish real login, suspend/resume, physical power-loss, clean-machine independence or human desktop acceptance. Linux package checks use Xvfb and disposable ext4, not a real GNOME Wayland session. Native APFS and Windows package checks cover their stated automated scope. No new manual acceptance results have been supplied for this release. Windows/Linux remain unsigned; macOS remains ad-hoc signed. Recycling stays disabled.

Final promotion must retain the tested binaries without rebuilding, attach only the five supported application downloads, and verify public unauthenticated download hashes against retained CI artifacts.

## Final packages and publication — 2026-11-12

Source: `16a8b1a89eef529b3c246b6a41654a92755c5df1`, preserved in main by [PR #52](https://github.com/mglezz/dowlume/pull/52). All three build manifests identify version 0.7.0, this revision and `DirtyWorkingTree: false`. The five downloaded application hashes matched their CI manifests. Embedded portable-package manifests and updated offline guides were inspected. The same bytes were uploaded and promoted without rebuilding.

- [Windows final packages](https://github.com/mglezz/dowlume/actions/runs/43295416751): passed on Windows build 26100 x64. Upgrade from the pinned 0.6.0 installer via the production downloader/verifier/launcher, portable launch, languages and persistence, native tray, background/visible login preference, running-app guards, uninstall and profile/file preservation passed. Its native workflow includes custom-rule conflicts and stable folder collection.
- [macOS/Linux final packages](https://github.com/mglezz/dowlume/actions/runs/43295425100): passed on macOS 15.8.2 arm64/APFS and Ubuntu x64/ext4. Extracted packages exercised native organization, review/Keep/Snooze/Move/Undo, reopened journal, watcher/periodic drain, custom-rule conflicts and stable whole-folder collection. Linux reports `InstallUpgradeUninstall: false`; no new manual Ubuntu installation or GNOME session was measured.
- [Source checks](https://github.com/mglezz/dowlume/actions/runs/43295370997), [PR checks](https://github.com/mglezz/dowlume/actions/runs/43295421120) and [security checks](https://github.com/mglezz/dowlume/actions/runs/43295420961) passed. All 13 checks on the frozen source succeeded, including the additional PR candidate builds. Local validation passed 153 tests with 48 platform skips, formatting, 280 source files/568 local links and six packaging tests with one platform skip. The dependency audit reported no vulnerable packages.

The maintainer's explicit conditional publication authorization was applied after this review and successful exact-package verification. No additional manual acceptance is inferred. The evidence limits above remain in force.

Tag `v0.7.0` points to the frozen source. [Dowlume 0.7.0](https://github.com/mglezz/dowlume/releases/tag/v0.7.0) is published as latest stable, not a draft or prerelease, with only the five supported application downloads. Labels retain the 0.6.0 style with version, platform, Installer/Portable and architecture. All five public downloads were streamed without authentication and their SHA-256 values matched the retained artifacts. The published 0.6.0 assets were not modified.
