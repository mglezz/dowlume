# Dowlume 0.7.0 acceptance

[Español](../../es/releases/acceptance/0.7.0.md) · [Release notes](../0.7.0.md)

## Preparation — 2026-11-12

The maintainer explicitly requested a full review and authorized stable publication if verification succeeds, using the 0.6.0 naming and description scheme. This is conditional publication authorization, not a report of new manual testing. Final source, CI runs and exact package hashes will be recorded after candidate validation; existing 0.6.0 or development builds do not approve new bytes.

The release review updates packaged quick starts and current guides, switches Windows upgrade acceptance to the hash-pinned published 0.6.0 installer, avoids repeated preview journal reads, moves settings reads off the UI thread, skips minimized-window polling and fixes recursive database access after theme persistence failure. Regression tests preserve unresolved-file exclusion and theme rollback.

## Performance observation

A disposable local Windows 11 build 26200 x64 test used 100 files of 4 KiB and 2,000 completed history entries. Five Release runs before/after the journal-read change produced median preview times of 2,516.87 ms and 231.36 ms (about 10.9 times faster for this fixture). Individual runs were 2533.98, 2516.87, 2544.17, 1688.23, 1684.23 ms before and 258.64, 231.36, 249.80, 226.14, 216.33 ms after. The fixture used immediate readiness to isolate journal/preview overhead, with the production file hasher and SQLite store. Production readiness delays were not removed. This is not an end-to-end download latency, cross-platform performance baseline or clean-machine benchmark. No personal Downloads were used.

## Evidence limits

Hosted runners do not establish real login, suspend/resume, physical power-loss, clean-machine independence or human desktop acceptance. Linux package checks use Xvfb and disposable ext4, not a real GNOME Wayland session. Native APFS and Windows package checks cover their stated automated scope. No new manual acceptance results have been supplied for this release. Windows/Linux remain unsigned; macOS remains ad-hoc signed. Recycling stays disabled.

Final promotion must retain the tested binaries without rebuilding, attach only the five supported application downloads, and verify public unauthenticated download hashes against retained CI artifacts.
