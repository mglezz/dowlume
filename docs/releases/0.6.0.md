# Dowlume 0.6.0 — Periodic organization and application updates

[Español](../es/releases/0.6.0.md) · [Acceptance record](acceptance/0.6.0.md)

Version 0.6.0 is being prepared for Windows x64, macOS 15+ Apple Silicon, and Ubuntu 24.04 LTS x64 with GNOME. The existing [platform and filesystem scope](../user/platform-support.md) is unchanged.

## Changes

- Optional periodic organization: choose 1–1440 minutes, with 10 minutes as the default. Preview and confirm before activation. The first pass waits; subsequent passes wait a full interval after the previous pass completes. Pausing drains active work and every launch starts paused.
- Manual update checks in Settings. Registered Windows installations can download the official installer, verify its size and SHA-256, and open it after graceful shutdown. Install over the existing copy without uninstalling. Other distributions open the official release instructions. There is no background polling or automatic installation.
- Search files awaiting review without changing queue totals, and clearer tab-selection indicators.
- English/Spanish interface, confirmations, documentation, and compatible settings defaults for older profiles.

Busy, recent, excluded and partial downloads retain existing readiness checks. File operations keep no-overwrite moves, journaling, recovery and eligible Undo. Existing subfolders are not imported. Native recycling remains disabled.

## Installation and privacy

Close Dowlume and back up the complete profile before upgrading. Install the Windows package over the existing installation, or use `sudo apt install ./dowlume_0.6.0_amd64.deb` on Ubuntu. Extract portable archives completely into a separate permanent folder. Profiles and organized files are retained. Version 0.5.0 predates the update button, so the first upgrade to 0.6.0 uses the normal installer or archive.

Update checks contact GitHub only on request, with no account, credentials, filenames or paths. GitHub receives ordinary connection information such as an IP address. Checksums verify consistency with release metadata, not independent publisher identity. Windows/Linux packages remain unsigned; macOS uses an ad-hoc signature without Developer ID or notarization. The .NET runtime is included.

See the [user guide](../user/guide.md) for configuration, upgrade instructions and recovery.
