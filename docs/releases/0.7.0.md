# Dowlume 0.7.0 — Personalization and controlled automation

[Español](../es/releases/0.7.0.md) · [Acceptance record](acceptance/0.7.0.md)

Version 0.7.0 targets Windows x64, macOS 15+ Apple Silicon, and Ubuntu 24.04 LTS x64 with GNOME. The existing [platform and filesystem scope](../user/platform-support.md) is unchanged.

## Changes

- Light, dark and system appearance, saved per profile and applied immediately, including dialogs.
- An On/Off monitoring switch and optional automatic resumption when Dowlume opens. New and upgraded profiles start off until the initial preview and confirmation. Changed organization settings require new consent. Turning monitoring off also disables automatic resumption; closing the app preserves the preference.
- Optional collection of whole top-level folders into `Folders` or another distinct collection folder. Disabled by default, with an independent 20–1440 minute interval. Two stable observations are required, so the earliest move is after two intervals. Existing names are never merged or overwritten.
- Windows login startup in the tray by default, with a saved option to show the window. Manual opening still shows the window. Existing startup entries are upgraded without enabling disabled entries.
- Editable classification folders and up to 50 custom rules by extension, filename contains or filename starts with. Name rules take priority over extensions; duplicate assignments are rejected and ambiguous matches remain untouched. Includes the login and rule changes merged after 0.6.0.
- Faster preview preparation by avoiding a full journal read for every file. Hidden or minimized windows skip periodic overview/history queries; settings reads run off the UI thread. Long confirmations remain scrollable.
- English/Spanish interface, confirmations and offline guides, with compatible defaults for older profiles and graceful handling of theme persistence failures.

Busy, recent, excluded and partial downloads retain their existing readiness checks. Folder collection protects classification/review folders and recorded destinations, skips links, hidden/system or inaccessible contents and trees above 10,000 entries, and never reclassifies children. Folder moves appear in Activity without file aging or automatic Undo; interrupted folder moves require manual inspection and are never replayed. File operations retain journaling, recovery and eligible Undo. Native recycling remains disabled.

## Installation and privacy

Close Dowlume and back up the complete profile before upgrading. Install the Windows package over the existing installation, or use `sudo apt install ./dowlume_0.7.0_amd64.deb` on Ubuntu. Extract portable archives completely into a separate permanent folder. Profiles and organized files are retained. Version 0.6.0 installations can use **Settings → Check for updates**; registered Windows installations can download and verify the new installer and open it after shutdown, without uninstalling.

Update checks contact GitHub only on request, with no account, credentials, filenames or paths. GitHub receives ordinary connection information such as an IP address. Checksums verify consistency with release metadata, not independent publisher identity. Windows/Linux packages remain unsigned; macOS uses an ad-hoc signature without Developer ID or notarization. The .NET runtime is included.

See the [user guide](../user/guide.md) for configuration, upgrade instructions, folder restoration and recovery. Stability observations cannot guarantee another application will never reopen content; POSIX sharing locks are cooperative. Keep active working folders outside the monitored root.
