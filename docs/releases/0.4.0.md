# Dowlume 0.4.0

[English](#) · [Español](../es/releases/0.4.0.md)

[Version 0.4.0](https://github.com/mglezz/dowlume/releases/tag/v0.4.0), published on 2026-10-23, adds the supported macOS Apple Silicon workflow. The release uses the corrected rc.2 application packages without rebuilding them. Manual functional confirmation covered rc.1 on macOS and Windows; automated regression and package acceptance covered the shutdown correction in rc.2. The [acceptance record](acceptance/0.4.0.md) identifies the source, hashes, and scope of those checks.

## Changes

- Drain monitoring tasks before disposing their watcher, preventing an intermittent shutdown error.
- Enable native organization, monitoring, aging/review, Keep, Snooze, Move, eligible Undo and journal recovery on macOS 15+ ARM64, for local APFS folders on the same volume.
- Use exclusive atomic rename, verified file/directory descriptors and persistent volume/file identity. Ambiguous files are retained; Activity shows the observed location when available.
- Add native application/Dock menus, Command-comma for Settings, reopen handling and graceful Quit. Closing the window exits after draining work; there is no macOS tray mode.
- Add optional login startup for an installed `.app`, and copy a closed 0.3.0 preview profile into the new `Dowlume` profile without deleting the original.
- Package the native adapter, icon, English/Spanish resources and offline guides. Package checks exercise the actual extracted macOS binary, including the full native workflow and both language tabs.
- Retain Windows functionality and test package upgrades from the published 0.3.0 installer. Linux stays a restricted preview for the 0.5.0 milestone.

New profiles classify `.dmg` and `.pkg` as Installers. Migrated category rules are preserved; these extensions can be added in Settings if they were absent. Application bundles are directories and are not imported as downloads.

## Boundaries

The macOS adapter refuses cross-volume moves, hard links, symbolic links, network/non-APFS storage and known cloud-managed locations. Detection cannot certify every third-party sync provider; I support only ordinary local folders outside synchronization services. Concurrent POSIX writers do not have to honor cooperative locks. Verification runs after rename and retains files on a detected race. It cannot exclude arbitrary writers or provide automatic rollback. See the [contract](../architecture/file-operations.md).

Native recycling remains disabled. Intel Macs remain excluded. Developer ID, notarization, and Windows publisher signing remain deferred to final stabilization; macOS has an ad-hoc signature. Installation may require the OS's explicit approval for an unsigned publisher. The installation procedure does not remove quarantine or disable Gatekeeper.

For installation, migration, backup and uninstall, see the [user guide](../user/guide.md#macos-040).
