# Dowlume 0.7.2 — Reopen the running application

[Español](../es/releases/0.7.2.md)

Unreleased maintenance update. Published 0.7.1 downloads remain unchanged.

Opening Dowlume again now requests activation of the instance already using the same profile. Its existing window is shown and restored from the tray or a minimized state; a maximized window remains maximized. An open confirmation remains accessible. The secondary launcher exits without opening the database or starting another monitor.

The exclusive profile lock remains in place. Activation uses a bounded, same-user local pipe scoped to the profile; it accepts only an activation request, not paths or arbitrary commands. Windows foreground permission is delegated to the existing process where the OS permits it. An unavailable or older instance without this channel retains the startup-error fallback instead of opening the profile concurrently.

Regression tests cover repeated/concurrent requests, independent profiles, listener shutdown/restart and window restoration. Windows package acceptance launches a second process while the first is visible, minimized and hidden, and checks that the original process is restored and the launcher exits successfully.
