Dowlume 0.7.0 — macOS Apple Silicon

Requires macOS 15+, Apple Silicon, and local APFS folders on the same volume.
The .NET runtime and both interface languages are included. Intel is not supported.

INSTALL

Quit the previous version, extract the ZIP, and move the complete Dowlume.app
to Applications before opening it or enabling login startup.

The app uses an ad-hoc signature without Developer ID or notarization. macOS may
block first launch. If macOS offers Open Anyway in System Settings > Privacy &
Security, use it only after checking the download source and published checksum.
Do not remove quarantine or disable Gatekeeper.

FIRST USE

Start with sample copies: Settings > folder > Preview > Organize and monitor.
Monitoring is off initially; later startup follows the saved preference. Closing the window or choosing Quit drains work and exits.
Command-comma opens Settings. Finder reveals selected files. Optional login startup
requires an installed .app and takes effect at the next login; macOS Login Items
can override it. To uninstall, disable login startup, quit, and remove the app.
The local profile and managed files are retained.

DATA AND LIMITS

The profile is stored in ~/Library/Application Support/Dowlume. First launch copies
a closed Dowlume.Preview profile only if the new profile is absent, preserving the
original. Back up the complete closed profile and managed files before upgrading.
Profiles cannot be imported from another operating system.

Cross-volume moves, hard links, symlinks, non-APFS/network storage, and known cloud
locations are refused. Keep actively edited or synchronized files outside the
managed folder. A concurrent writer can cause NeedsAttention; retain the files
and inspect Activity. Recycling remains disabled.

VERSION 0.7.0

Settings offers optional periodic organization (1-1440 minutes, default 10).
Preview and confirm before enabling it; the first pass waits for the interval.
Off stops both monitors and disables automatic resumption.

Check for updates contacts GitHub only when requested, without sending filenames
or paths. Registered Windows installations can download and verify the installer
and open it after shutdown, without uninstalling. Other packages open official
release instructions. Windows/Linux are unsigned; macOS is ad-hoc signed.


NEW IN 0.7.0

Choose System, Light or Dark appearance in Settings; it saves immediately.
Edit classification folders or add extension, name-contains or starts-with rules.
Duplicates are refused and files with ambiguous matches remain untouched.
Resume monitoring when Dowlume opens is optional: save the preference, inspect
Preview and confirm the initial start. Changed rules require new consent.
Off also disables automatic resumption; closing preserves the preference.
Collect loose folders is optional and disabled by default. Use Folders or a
collection name distinct from your categories. Checks run every 20-1440 minutes
and require two stable observations (earliest move: at least 40 minutes).
Classification folders, links, incomplete, hidden or inaccessible contents, and
trees above 10,000 entries are skipped. Never merges, overwrites or deletes.
Folder moves appear in Activity without Undo or age-based review. To restore a
folder, turn monitoring off and use your file manager. Interrupted folder moves
require manual inspection and are never replayed automatically.
