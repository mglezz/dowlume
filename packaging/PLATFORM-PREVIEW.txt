Dowlume — experimental Linux preview

This package tests the platform foundation on Ubuntu 24.04 x64. It provides
folder preview, settings, language selection, history inspection, and folder
reveal. File moves, monitoring, review actions, Undo, and automatic recovery are
disabled. It is not a supported Linux release.

Extract the complete archive, retaining the runtime files and the es directory.
The runtime is included. Use disposable copies in a local folder. A graphical
X11/XWayland session and native libraries are required; see the platform guide
for the tested environment. Login startup and hiding to the tray are unavailable.
The file-manager action opens the containing folder.

The preview uses a separate Dowlume.Preview profile. Do not import a database
from another operating system: historical paths are specific to their source OS.
Native desktop, permission, and file-safety acceptance remain work for 0.5.0.
