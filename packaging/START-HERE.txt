Dowlume - Your downloads, under control

GET STARTED

1. Run Dowlume.App.exe. Keep all files in this package together.
   The .NET runtime is included; no separate runtime installation is needed.
2. In Settings, choose a disposable folder containing COPIES of sample downloads.
   Save settings, open Preview, and select Refresh preview.
3. Check the proposed destinations. Organize and monitor asks for confirmation
   before moving files. It also covers future completed downloads in that folder.
4. Pause stops monitoring. Closing the window stops the app. Hide to tray keeps
   it running; use the notification-area icon (possibly under Show hidden icons)
   to reopen it or exit. Settings offers an optional Windows sign-in startup
   setting, off by default. Windows login starts in the tray by default; the window is optional.
5. When comfortable with the workflow, choose your local Downloads folder.

REVIEW AND RECOVERY

Aging files move into Expiring Files for your decision. Keep excludes a file
from further age reviews. Snooze returns it to its category for seven days.
Move lets you choose another folder. Recycling remains disabled because
Windows Recycle Bin could not reliably preserve files. Leave files in Review
or use Keep, Snooze, or Move. Recoverable quarantine is future work.

Activity provides search, filters, paths, and undo for eligible actions.
Undo requires unchanged content and an available original location. Historical
Recycle records do not guarantee a recoverable copy. For an interrupted move,
inspect the recorded paths before choosing Retry interrupted operations.
Ambiguous copies are preserved. Do not delete either copy without checking it.

FILES AND PRIVACY

File classification discovers direct files only. Whole-folder collection is
separately optional and disabled by default. Automatic monitoring requires the saved opt-in and initial consent. Network shares,
symbolic links, junctions, and cloud placeholders are unsupported.

Keep backups of valuable files. Close Dowlume before upgrading or uninstalling.
Uninstall retains your organized files and profile in %LOCALAPPDATA%\Dowlume.
The private database contains file paths and hashes. Exit the app before backing
up that entire folder. No account, cloud synchronization, or telemetry is used.

VERSION 0.7.0

Settings offers optional periodic organization (1-1440 minutes, default 10).
Preview and confirm before enabling it; the first pass waits for the interval.
Off stops both monitors and disables automatic resumption.

Check for updates contacts GitHub only when requested, without sending filenames
or paths. Registered Windows installations can download and verify the installer
and open it after shutdown, without uninstalling. Other packages open official
release instructions. Windows/Linux are unsigned; macOS is ad-hoc signed.


NEW IN 0.7.0

Choose System, Light or Dark appearance in Settings; it saves immediately.
Edit classification folders or add extension, name-contains or starts-with rules.
Duplicates are refused and files with ambiguous matches remain untouched.
Resume monitoring when Dowlume opens is optional: save the preference, inspect
Preview and confirm the initial start. Changed rules require new consent.
Off also disables automatic resumption; closing preserves the preference.
Collect loose folders is optional and disabled by default. Use Folders or a
collection name distinct from your categories. Checks run every 20-1440 minutes
and require two stable observations (earliest move: at least 40 minutes).
Classification folders, links, incomplete, hidden or inaccessible contents, and
trees above 10,000 entries are skipped. Never merges, overwrites or deletes.
Folder moves appear in Activity without Undo or age-based review. To restore a
folder, turn monitoring off and use your file manager. Interrupted folder moves
require manual inspection and are never replayed automatically.
